# The rule for a chat Broca listens to

Broca speaks exactly one thing: a paragraph that begins with `» ` (U+00BB, then one space) at the start of a line. So:
a reply that holds real information for the person starts with one spoken line, in plain terms, one or two sentences; the
rest of the reply stays on screen and is not spoken. No filler ("hmm, looking into it" is forbidden). One spoken line
per reply; mid-task, another only when there is real news. For a page: the spoken line says in one sentence what the
page shows and asks "did you open the page?"; walk it through only after their yes. Never start a line with `» ` that
is not meant to be heard; to show the marker, put it in a code fence or mid-line.
